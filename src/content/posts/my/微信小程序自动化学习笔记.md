# 小程序抓包
需要用到的工具：
+ Reqable：用于分析数据包内容
+ Proxifier：用于拦截特定进程的数据包
## 1.配置Proxifier

安装Proxifier，

打开界面 -> Profile -> Proxification Rules

配置以下规则：
Name：随意 
Applications：
```unknown
WeChat.exe;WeChatAppEx.exe;WeChatBrowser.exe;WXWorkWeb.exe;WXDirve.exe;WXWork.exe;
```
Action：选刚配置的Proxy HTTPS 127.0.0.1
其他默认，完成，将该规则调到最上方即可

打开界面 -> Profile -> Proxy Servers -> Adds
添加新的Server：
Address：`127.0.0.1`  Port：`9000` （这里的地址是Reqable的默认代理服务器地址，可自行灵活调配）
Protocol：选HTTPS
其他默认，完成即可。
