## 安装
不会安装

## 快捷键

| 快捷键               | 功能说明                                   |
| ----------------- | -------------------------------------- |
| `Enter`           | 发送当前输入内容（AI 执行中发送则默认为 **Steering 引导**） |
| `Shift + Enter`   | 输入框内换行（避免直接发送）                         |
| `Alt + Enter`     | 将指令作为 **Follow-up（排队）** 提交             |
| `Alt + ↑`         | 取回正在排队中的 Follow-up 指令并重新编辑             |
| `Ctrl + L`        | 快速唤出模型选择器（Model Selector）              |
| `Shift + Tab`     | 循环切换当前模型的思考强度（Thinking Effort）         |
| `Ctrl + G`        | 唤起系统记事本/外部编辑器编辑长提示词，保存并关闭后同步回终端        |
| `Alt + V`         | 粘贴剪贴板截图至对话框供多模态模型分析                    |
| `Ctrl + O`        | 在 `/tree` 对话树回退操作中展开/折叠历史摘要详情          |
| `Ctrl + C` (连按两次) | 退出 Pi Agent 终端会话                       |
## 交互命令

| 命令         | 参数 / 格式        | 功能详解                                                                  |
| :--------- | :------------- | :-------------------------------------------------------------------- |
| `/login`   | 无              | 配置模型凭证。支持 40+ 供应商的 API Key，或通过 `Sign in with account` 登录 OpenAI 订阅账户。 |
| `/model`   | `[model_name]` | 切换当前使用的模型（例如切换为 `deepseek-v4-flash`）。                                 |
| `/new`     | 无              | 清空当前上下文，开启全新 Session（最佳实践推荐，避免旧记忆干扰）。                                 |
| `/tree`    | 无              | 展开当前 Session 的对话树，支持选定历史节点进行分支回退与分叉试验。                                |
| `/clone`   | 无              | 完整克隆当前 Session 的整棵对话树为新的独立 Session。                                   |
| `/fork`    | 无              | 选定对话树中的某一历史节点，仅携带该节点之前的历史分叉出新 Session。                                |
| `/compact` | 无              | 手动触发上下文压缩与精简，释放窗口占用。                                                  |
| `/reload`  | 无              | 重新加载项目与全局目录下的插件/扩展（Extensions）。                                       |

  

### 行内上下文修饰符

  

* `@<文件路径>`：引用本地文件内容注入对话上下文（如 `@src/main.ts`）。

* `!<shell命令>`：在当前会话临时执行终端命令，**输出结果对 AI 可见**（如 `!npm run dev`）。

* `!!<shell命令>`：在当前会话静默执行终端命令，**执行过程与输出对 AI 完全隐藏**。
